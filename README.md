## Overview

This repository contains the source code for my personal portfolio website, built entirely with **Flutter Web**.

The portfolio is designed to showcase my journey as a **Software Engineer & Flutter Developer**, including my technical skills, projects, experience, and open-source contributions.

The design focuses on a premium developer experience with :

- Dark modern aesthetic
- Glassmorphism UI
- Smooth custom animations
- Fully responsive layouts
- Interactive project sections
- Modular and scalable architecture

The goal is to combine **strong engineering practices** with a polished and memorable user experience.
